# 🗺️ מפת אירועים

מקבלת אירוע חדשותי ומחזירה את המניות והמדדים האמריקאיים שהוא משפיע עליהם.

- **חדשות:** פיד כותרות חי מאתרי חדשות בינלאומיים ואתרי כלכלה, מתורגם לעברית. לחיצה על "נתח" מושכת את הכתבה המלאה לטופס הניתוח.
- **ניתוח:** Claude מאמת את האירוע מול אתרי חדשות, מתייג אותו (one-off או process) ובוחר 10 מניות ומדדים עם כיוון, מנגנון וציון חשיפה. עובד גם בלי מפתח API, דרך הצ'אט הרגיל של Claude.
- **מחירים:** שנה של נרות יומיים לכל טיקר: סגירה, שינוי חודשי, סף גאפ של 2σ וציון z של הגאפ האחרון.
- **יומן תרחישים:** כל ניתוח נשמר בדפדפן, עם מקום לרשום מה קרה בפועל.

## פריסה ל-Vercel (קישור קבוע)

1. מחברים את הריפו ב-[vercel.com/new](https://vercel.com/new). ההגדרות נקבעות מהקוד (`vercel.json`), אין צורך לשנות כלום.
2. לוחצים Deploy. זהו.

**בלי מפתח API** האפליקציה מציגה חדשות, מושכת כתבות ושומרת יומן. הניתוח נעשה דרך הכפתור **"פתח ב-Claude"**: הוא מעתיק את הכתבה עם כל כללי המחקר ופותח את Claude בלשונית חדשה. מדביקים (Ctrl+V), שולחים, ואת התשובה מדביקים חזרה ביומן. אין עלות מעבר למנוי.

**עם מפתח API** (לא חובה, אפשר להוסיף מתי שרוצים) הניתוח רץ בתוך האפליקציה, כולל אימות אוטומטי מול אתרי חדשות, טבלאות ומחירים. ב-Vercel: **Settings ← Environment Variables**, מוסיפים:

| משתנה | ערך |
|---|---|
| `ANTHROPIC_API_KEY` | מפתח מ-[console.anthropic.com](https://console.anthropic.com) (דורש קרדיט, בנפרד מהמנוי) |
| `APP_PASSWORD` | סיסמה שתבחר. **חובה יחד עם המפתח**: בלעדיה הניתוח בתוך האפליקציה לא יופעל, כדי שאף אחד אחר לא ישתמש במפתח שלך. |

אחרי ההוספה: **Deployments ← ⋯ ← Redeploy**. מומלץ להגדיר גם תקרת הוצאה חודשית ב-console.anthropic.com תחת Limits.

## הרצה מקומית

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm start            # http://127.0.0.1:8787
npm test             # בדיקות יחידה
```

כשמריצים מקומית אין צורך בסיסמה, אלא אם מגדירים `APP_PASSWORD`.

## מקורות

| שכבה | מקור | הערות |
|---|---|---|
| **פיד חדשות** | כלכלה: Bloomberg Markets, Bloomberg Economics, Wall Street Journal, Financial Times, Yahoo Finance, MarketWatch, CNBC, CNBC Economy, BBC Business. כללי: Google News (כותרות של Reuters, AP ו-Bloomberg), BBC World, Al Jazeera, Guardian, NYT | הרשימה ב-`lib/sources.js`, ומקור חדש מוסיפים בשורה אחת. מטמון של 5 דקות. |
| **תרגום** | Google Translate (חינמי, בלי מפתח, כמו בסורק החדשות) | הכותרות והתקצירים מוצגים בעברית, והכותרת המקורית קטנה מתחת. אפשר לכבות. הניתוח עצמו נעשה על הטקסט המקורי. |
| **משיכת כתבה** | כל קישור לכתבה | כתבה מאחורי חומת תשלום תחזיר רק כותרת. |
| **אימות** | Claude עם חיפוש ברשת, מוגבל לאתרי חדשות מרכזיים | רק במצב "אמיתי". |
| **ניתוח** | Claude API (`claude-opus-5`) | כשמודל מסרב, הבקשה עוברת אוטומטית למודל גיבוי. |
| **מחירים** | Yahoo Finance, ו-Stooq כגיבוי | לא בזמן אמת. |

**ציון החשיפה** הוא הערכה של Claude עם נימוק, ולא אומת מול נתוני חברה. גרסת ה-Artifact אימתה אותו דרך IBKR, אבל החיבור הזה קיים רק בתוך claude.ai.

**היומן** נשמר בדפדפן שבו עשית את הניתוח. כדי להעביר אותו למכשיר אחר, משתמשים ב"ייצוא לקובץ" ו"ייבוא מקובץ".

## משתני סביבה נוספים

| משתנה | ברירת מחדל | |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5` | |
| `CLAUDE_EFFORT` | `high` | `low` או `medium` זולים ומהירים יותר |
| `ANALYZE_LIMIT_PER_HOUR` | `20` | מספר ניתוחים לשעה מכל כתובת IP |
| `VERIFY_DOMAINS` | רשימת אתרי חדשות | מופרדים בפסיקים |
| `PORT` / `HOST` | `8787` / `127.0.0.1` | להרצה מקומית בלבד |

## מבנה הפרויקט

```
lib/sources.js  רשימת פידי החדשות
lib/news.js     הורדה ופענוח של RSS/Atom, חילוץ טקסט מכתבה
public/prompt.js הפרומפט וכללי המחקר (משותף לשרת ולכפתור "פתח ב-Claude")
lib/claude.js   הקריאה ל-Claude API
lib/prices.js   נתוני מחיר וחישוב σ של גאפים
lib/api.js      סיסמה, הגבלת קצב וכלים משותפים
api/            פונקציות השרת (Vercel)
public/         הממשק
server.js       שרת להרצה מקומית
```

כלי מחקר בלבד. זו לא המלצת השקעה ולא פקודת מסחר.
